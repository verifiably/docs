Start by auditing the READMEs of atoms, nodes, beliefs, science and autonomy: what is present, missing, misplaced, or out of date.

Then design a template kept in verifiably/docs. A starting sketch, not final:

    <logo> <project name>
           <slogan>            e.g. "Recoverable filesystem effect engine"
    <verifiably mini block>    ecosystem summary + mini-nav to every project, current one unlinked
    <overview>
    <installation>
    <usage>
    <links to detailed docs>
    <license>

Also consider PyPI/npm package links and links both ways between each project and verifiably/docs.

Findings already known: detailed bookkeeping (e.g. atoms' status section) belongs in docs/; local links like ~/d/beliefs and ~/d/mindful/v6 should be GitHub links (private repos go public later).

Review each README's substance for accuracy too, not only structure.

Rollout would cover autonomy-6e0015 and sci-edc546 (point the README at the ecosystem overview).
